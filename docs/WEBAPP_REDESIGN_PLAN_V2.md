## ۲. جهت طراحی (Design System v2)

**اصل:** «آرام در تاریک، شاداب در روشن». هر بخش رنگ خودش را دارد و همین رنگ در آیکون، تب فعال، هدر کارت و نمودار تکرار میشود.

| بخش | تاریک | روشن | دلیل |
|---|---|---|---|
| پایه / برند | سرمهای عمیق + فیروزهای کاور | پسزمینهٔ گرم شیری `#FBFAF7`، کارت سفید با سایهٔ نرم | تیره نزدیک کاور میماند و روشن دیگر «نونی» نیست |
| منابع و آموزش | ایندیگو | `#4F46E5` | |
| بانک سؤال و آزمون | بنفش | `#7C3AED` | |
| برنامه | کهربایی | `#F59E0B` | |
| هوشیار | گرادیان فیروزهای به آبی | `#06B6D4 → #3B82F6` | |
| کارنامه و نمرات | زمردی | `#10B981` | |
| اشتراک و پول | سبز | همان سبز دکمههای ربات | هماهنگ با ربات |
| یادداشتها | زرد عسلی | `#EAB308` | |
| هشدار و حذف | رز | `#F43F5E` | هماهنگ با قرمز ربات |

- **توکنها:** سه لایه (primitive → semantic → component) طبق اسکیل `design-system`. شامل مقیاس تایپ (Vazirmatn، اعداد فارسی)، فاصلهٔ ۴/۸، شعاع، سایه، حرکت با `prefers-reduced-motion`.
- **دسترسپذیری:** کنتراست AA در هر دو تم (بهطور خودکار چک میشود). هدف لمسی ۴۴px.
- **تایپوگرافی:** طبق اسکیل `better-typography`. شامل نیمفاصله (ZWNJ)، اعداد فارسی، طول خط، شکست خط RTL و `dir="auto"` برای متن مختلط.
- **قبل از اعمال روی کل اپ:** یک صفحهٔ moodboard (هر دو تم، ۴ صفحهٔ نمونه روی iPhone و دسکتاپ) میسازم تا تو تأیید کنی. **این ایست بازرسی ۱ است.**

## ۴. هوشیار — فهرست کامل قابلیتها (همحس ChatGPT)
- **تاریخچه:**
  - کشوی کناری در موبایل و ستون ثابت در دسکتاپ.
  - گروهبندی امروز، دیروز، ۷ روز اخیر و قدیمیتر.
  - جستجو، سنجاق، تغییر نام، حذف (با undo)، و گفتگوی جدید.
  - عنوان خودکار از اولین پیام.
- **پیامها:**
  - streaming روان با دکمهٔ توقف.
  - ساخت دوبارهٔ پاسخ.
  - ویرایش پیام و ارسال دوباره.
  - کپی و بازخورد 👍/👎.
  - دکمهٔ «رفتن به آخر».
  - پیشنویس ذخیرهشده.
- **رندر:** Markdown، جدول، کد با هایلایت و دکمهٔ کپی، فرمول، و جهت خودکار RTL/LTR برای هر پاراگراف.
- **ورودی:**
  - پیوست عکس (vision از قبل وجود دارد).
  - پیشنهادهای شروع پزشکی.
  - Enter برای ارسال و Shift+Enter برای خط جدید در دسکتاپ، و ورودی چندخطی رشدکننده در موبایل.
- **بکاند:** اول بررسی میکنیم که `/api/ai/ask` پیامها را در گفتگو ذخیره میکند یا نه. endpointهای کمبود (regenerate، edit، feedback، search) فقط افزایشی اضافه میشوند و سازگاری با ربات و مینیاپ حفظ میشود.
- **ورودی صوتی:** فقط اگر سرور transcription داشته باشد. وگرنه به مرحلهٔ بعد میرود و ساختگی ساخته نمیشود.
